# clips-expert-systems
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Гриценко Руслан
- Група: ІН-31

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

Висновок:
Під час виконання лабораторних робіт з середовища CLIPS було опановано основні принципи побудови експертних систем та організації баз знань. Було освоєно створення структурованих шаблонів (deftemplate) і фактів (deffacts) для опису реальних об'єктів та взаємозв'язків між ними. Вивчення правил (defrule) дозволило зрозуміти механізми автоматичного аналізу даних і формування логічних висновків на основі зіставлення зі зразком. Також було розглянуто створення власних процедурних функцій (deffunction) та перетворення звичайних математичних виразів у префіксну форму. На практичних прикладах із класифікацією пожеж та моніторингом датчиків було відпрацьовано обробку невідомих даних і керування порядком виконання правил. У результаті виконання завдань було здобуто практичні навички декларативного та продукційного програмування для розв'язання різноманітних логічних завдань.
